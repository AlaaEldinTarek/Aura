# Release 1.1.0 (versionCode 60) — Play Console release notes

Contents: FX-0 (PR #1) + F51a (PR #2) + F57 + F58 (PR #3). Paste each block as plain text (max 500 characters each).

## en-US
```
• Prayer times follow your settings exactly: Hanafi Asr and the Qatar, Dubai, Turkey, Singapore and Moonsighting Committee methods. Changes apply at once.
• Calculation method and Asr madhab are now separate options: pick one, then tap Done.
• More accurate adhan timing when the app is closed, including daylight-saving changes.
• Daily prayer summary fixed on phones using Arabic digits (no more lost answers).
• Quran reader: A− / A+ moved into the bottom bar, so they no longer cover the text.
```
